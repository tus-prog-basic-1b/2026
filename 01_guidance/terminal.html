VS Code の使い方 & Terminalのおさらい¶

VS CodeをWSLのUbuntuに接続し、授業用のフォルダーを開きます。「View → Terminal」でUbuntuのターミナルを表示してください。

現在の場所とファイルを確認する¶

最初に、自分が今どこにいるのかを確認してみましょう。ターミナルで以下のコマンドを実行してください。

$ pwd
$ ls

pwd は現在のディレクトリ、ls はその中のファイルやディレクトリを表示します。 Linuxのターミナルを開くと、最初の位置は ホームディレクトリ と呼ばれるディレクトリで、 pwd を実行すると /home/<ユーザ名> と表示されると思います。これがあなたのホームディレクトリです。

WSL2では、このLinuxのディレクトリはWindows側からも見ることができます。Windowsでフォルダーアプリを開くと、通常のストレージとは別に、ペンギンロゴが付いた「Linux」という項目が見えると思います。この下に「Ubuntu」という名前のフォルダがあり、home → <ユーザ名> と辿ると、第1回で作ったhello.cなどが見えるはずです。

絶対パスでは、 ¥¥wsl.localhost¥Ubuntu¥home¥<ユーザー名> のように表示されます。

ディレクトリを作って移動する¶

次に、今日の講義のプログラムを保存・編集するための作業スペースとして、専用ディレクトリを作りましょう。

$ mkdir -p ~/prog-basic-b1/week02
$ cd ~/prog-basic-b1/week02
$ pwd

mkdir はディレクトリを作成するコマンド (make directory) で、cd は指定したディレクトリへ移動するコマンド (change directory) です。 ~ はUbuntuのホームディレクトリ /home/<ユーザ名> を表します。 つまり、これらのコマンドは「ホームディレクトリ直下に prog-basic-b1/, 更にその下に week02/ というディレクトリを作り、その作成したディレクトリへ移動してください」という意味になります。コマンドが正しく成功すると、後述のプログラムや実行ファイルは全て ~/prog-basic-b1/week02/ に保存されます。

今後この授業では、各週ごとに作業ディレクトリを ~/prog-basic-b1/ 以下に作ります。例として、第3回の授業用に week03/ のディレクトリを作ってみましょう。

$ cd ..
$ mkdir week03
$ ls

.. は自分の現在のディレクトリから一つ上の階層を表します。 つまりここでは、今いるディレクトリ ~/prog-basic-01/week02 から一つ上の階層 ~/prog-basic-01/ へ移動し、その直下に week03/ を作成しています。 ls を実行すると、 week02/ week03 の2つのディレクトリが見えると思います。

また、便利な機能として、ディレクトリを指定せず cd のみ実行すると、ホームディレクトリへ移動できます。

$ cd
$ pwd

それでは、week02/へ戻って次ページ「C言語の基礎」へ進みましょう。 

$ cd ~/prog-basic-b1/week02
$ pwd

参考: プログラムの編集と保存方法¶

$ code none.c

上記のコマンドをターミナルで実行すると、VS Codeのエディタで none.c という名前のファイルが新しく開きます。プログラムを書き込んでから Ctrl+S で保存すると、Ubuntuターミナルの現在のディレクトリの同名のファイルが保存されます。

参考: コンパイル・実行方法¶

$ gcc none.c
$ ./a.out

1行目: gcc がソースファイルから実行ファイルを作ります。実行ファイルの名前は、何も指定をしない場合は a.out となります。

2行目: a.outを実行します。./ は現在のディレクトリを表すため、このコマンドは「現在のディレクトリ (./) にある a.out を実行してください"という意味になります。 プログラムを変更したら、変更を実行ファイルに反映させるために再度コンパイルをしてください。

参考: ターミナル操作のコツ¶

  • ファイル名やディレクトリ名の大文字・小文字は区別されるので注意しましょう。
  • 入力途中で Tab を押すと名前を補完できます。
  • 上矢印キーを押すと、直前に実行したコマンドを表示してそのまま実行できます。
  • 実行中のプログラムを止めるときは Ctrl+C を使います。
  • 教材にある $ は入力待ちの記号です。コマンドと一緒に入力しません。
