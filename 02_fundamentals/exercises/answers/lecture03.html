第3回 変数と演算子の解答例¶

教材目次

基礎演習3〜5の解答例である。代入、書式指定子、整数の除算と剰余を確認する。各コードはそれぞれ別のCファイルとして保存する。

演習3 整数の代入¶

exe03_1.c に保存する。

#include <stdio.h>

int main(void) {
    int i;
    i = 10;
    printf("%d\n", i);
    return 0;
}

出力例：

10

int i; で整数型の変数を宣言し、i = 10; で値を代入する。整数の出力には %d を使う。

演習3 文字の代入¶

exe03_2.c に保存する。

#include <stdio.h>

int main(void) {
    char c;
    c = 'a';
    printf("%c\n", c);
    return 0;
}

出力例：

a

文字は 'a' のように一重引用符で囲み、%c で出力する。"a" は文字列なので区別する。

演習4 加算¶

exe04.c に保存する。

#include <stdio.h>

int main(void) {
    int i = 10;
    i = i + 1;
    printf("i = %d\n", i);
    return 0;
}

出力例：

i = 11

右辺の i + 1 を計算してから、結果を左辺の i に代入する。i += 1; や i++; でも1増やせる。

演習5 四則演算¶

exe05.c に保存する。

#include <stdio.h>

int main(void) {
    printf("%d\n", 7 + 3);
    printf("%d\n", 7 - 3);
    printf("%d\n", 7 * 3);
    printf("%d\n", 7 / 3);
    printf("%d\n", 7 % 3);
    return 0;
}

出力例：

10
4
21
2
1

整数同士の 7 / 3 は整数の商 2、7 % 3 は余り 1 である。

演習5 計算式も表示する¶

余裕がある場合の改良例である。

#include <stdio.h>

int main(void) {
    printf("7 + 3 = %d\n", 7 + 3);
    printf("7 - 3 = %d\n", 7 - 3);
    printf("7 * 3 = %d\n", 7 * 3);
    printf("7 / 3 = %d\n", 7 / 3);
    printf("7 %% 3 = %d\n", 7 % 3);
    return 0;
}

出力例：

7 + 3 = 10
7 - 3 = 4
7 * 3 = 21
7 / 3 = 2
7 % 3 = 1

printf の書式文字列で % 自体を表示するときは %% と書く。計算に使う剰余演算子は % である。
