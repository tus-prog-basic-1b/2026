第3回 AtCoder応用演習の解答例¶

AtCoder応用演習について¶

問題一覧の7問に対応します。まず自力で取り組み、解答は振り返りに使ってください。標準入力の scanf は第4回の先取りです。ここでは問題の制約を満たす入力が与えられるものとします。提出時には入力を促すメッセージを出力しません。以下は公式問題文に基づいて作成した解答例で、公式解説の転載ではありません。

ABC001A 積雪深差¶

公式問題文

#include <stdio.h>

int main() {
    int h1, h2;
    scanf("%d%d", &h1, &h2);
    printf("%d\n", h1 - h2);
    return 0;
}

入力例：

15
10

出力例：

5

現在の積雪深から1時間前の積雪深を引きます。減少した場合は負の値になります。

ABC007A 植木算¶

公式問題文

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    printf("%d\n", n - 1);
    return 0;
}

入力例：

4

出力例：

3

一直線に並ぶ木が n 本なら、その間は n - 1 箇所です。

ABC017A プロコン¶

公式問題文

#include <stdio.h>

int main() {
    int s1, e1, s2, e2, s3, e3;
    scanf("%d%d", &s1, &e1);
    scanf("%d%d", &s2, &e2);
    scanf("%d%d", &s3, &e3);
    printf("%d\n", s1 * e1 / 10 + s2 * e2 / 10 + s3 * e3 / 10);
    return 0;
}

入力例：

50 7
40 8
30 9

出力例：

94

評価 e は配点の何割を得るかを表すので、各得点は s * e / 10 です。配点は10の倍数のため、整数演算で求められます。

ABC134A Dodecagon¶

公式問題文

#include <stdio.h>

int main() {
    int r;
    scanf("%d", &r);
    printf("%d\n", 3 * r * r);
    return 0;
}

入力例：

4

出力例：

48

問題で与えられた面積の式をそのまま計算します。Cの ^ は累乗の演算子ではありません。

ABC003A AtCoder社の給料¶

公式問題文

#include <stdio.h>

int main() {
    int n;
    scanf("%d", &n);
    printf("%d\n", 5000 * (n + 1));
    return 0;
}

入力例：

6

出力例：

35000

1から n の平均は (n + 1) / 2 なので、期待値は 10000 * (n + 1) / 2、すなわち 5000 * (n + 1) 円です。整数で先に (n + 1) / 2 を計算すると端数を失う場合があります。

ABC192A Star¶

公式問題文

#include <stdio.h>

int main() {
    int x;
    scanf("%d", &x);
    printf("%d\n", 100 - x % 100);
    return 0;
}

入力例：

140

出力例：

60

100で割った余りを100から引きます。すでに100の倍数の場合も、次の報酬までには100枚必要です。

ABC057A Remaining Time¶

公式問題文

#include <stdio.h>

int main() {
    int a, b;
    scanf("%d%d", &a, &b);
    printf("%d\n", (a + b) % 24);
    return 0;
}

入力例：

23 2

出力例：

1

時刻と経過時間を足し、24で割った余りで0〜23時に戻します。
