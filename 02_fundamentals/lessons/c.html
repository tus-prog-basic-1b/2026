C言語の基礎¶

C 言語でのプログラミング¶

C言語は、 手続き型言語 です。 手続き型言語とは、 命令を順に並べて記述するプログラミング言語 のことです。

手続き型言語では、一番最初の命令を記述する場所があります。 コンピュータは、そこから上から下に向けて順に命令を実行していきます。

C言語では、 命令の開始場所をmainという関数 で与えます。

C言語の実行¶

C言語は コンパイラ言語 です。 事前にプログラムを コンパイル して機械語に翻訳する必要があります。 コンパイラの作成した機械語のファイルを 実行ファイル と呼びます。

C言語プログラミングの手順¶

何もしないプログラム「 none.c 」の作成を通して、C 言語でのプログラミングの流れを説明します。

1. プログラム作成¶

WSLに接続したVS CodeでC言語のプログラムを作成します。以下のコマンドはVS CodeのUbuntuターミナルで実行します。

$ code none.c

none.c

int main( ) { }

プログラムファイルを保存します。（Ctrl+S） 保存したらVS Codeのターミナルでコンパイルします。 ファイル名の最後には「 .c 」を付けるのが慣習となっています。 ここでは、ファイル名を「 none.c 」とします。

2. コンパイル¶

gcc というコンパイラを用います。 gccとはGNU C Compilerの略でGNUという組織が開発したCのコンパイラです。 というのはすこし昔の話で、今はthe GNU Compiler Collectionの略です。 以下のようにして用います。

$ gcc none.c

gcc は、 none.c を読んで実行可能なプログラムに変換するコンパイラです。 gcc はファイル名の最後の .c を見て C 言語のプログラムであることを認識しています。 コンパイルの結果、実行可能なプログラム (実行ファイル) a.out が生成されます。 生成されているか確認します。

$ ls
a.out    none.c

gcc が生成する実行ファイルの名前は、特に指定しない場合、a.out となりますが、 実行ファイルの名前を変えたい場合は、以下のようにgcc の -o オプションを使います。

$ gcc -o none none.c

$ ls
none     none.c

この授業では、a.out のまま実行ファイル名を用います。

3. 実行¶

実行可能なプログラムのファイル名は a.out です。 これは、a.out というコマンドが作られたということです。 WSLのターミナルから ./a.out と入力すれば、a.out が実行されます。

$ ./a.out

実行が終了すると、端末に戻ってきます。 このプログラムは何も実行しないので、何も起きません。
