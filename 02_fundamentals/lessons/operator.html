算術演算子¶

C言語をはじめとするプログラミング言語では、算術演算子を使って数値の計算ができます。 演算子には、数学で用いる四則演算と余りを求める%があります。

  • +: 加算(addition)
  • -: 減算(subtraction)
  • *: 乗算(multiplication)
  • /: 除算(division)
  • %: 剰余(remainder, modulo operation)

演算子を用いた式の変数への代入¶

演算子を用いた式の変数への代入は「変数名 = 式」と書きます。 これは、右辺の式の値を、左辺の変数に格納することを示しています。 代入を行うと、元々入っていた値が更新されます。

op_1.c

#include <stdio.h>

int main( ) {
    int i = 2;
    int j = 3;
    int k = i * j;
    printf("k = %d\n", k);
}

右辺と左辺の両方に同じ変数が出現することがあります。 この場合も、まず右辺の計算をして、その値を左辺の変数に格納します。 次のような更新式をイメージしてください。

\(x_{t+1} = x_t + 10\)

op_2.c

#include <stdio.h>

int main( ) {
    int k = 1;
    k = k + 1;
    printf("k = %d\n", k);
}

代入を伴う演算子¶

更新式のような演算は、代入を伴う演算子として簡単に記述することができます。

  • x = x + 1; → x += 1;
  • x = x - 3; → x -= 3;
  • x = x * 2; → x *= 2;
  • x = x / 2; → x /= 2;
  • x = x % 2; → x %= 2;

op_3.c

#include <stdio.h>

int main( ) {
    int x = 10;
    printf("x = %d\n", x);
    x += 1;
    printf("x += 1: %d\n", x);
    x -= 3;
    printf("x -= 3: %d\n", x);
    x *= 2;
    printf("x *= 2: %d\n", x);
    x /= 2;
    printf("x /= 2: %d\n", x);
    x %= 2;
    printf("x %= 2; %d\n", x);
}

単項演算子¶

1足したり1引くだけのような更新式は、単項演算子でもっと簡単に記述することができます。

  • x = x + 1; → x += 1; → x++;
  • x = x - 1; → x -= 1; → x--;

この1を足していく演算子をインクリメント演算子(Increment Operator)と呼びます。 また、1を引いていく演算子をデクリメント演算子(Decrement operator)と呼びます。

op_4.c

#include <stdio.h>

int main( ) {
    int x = 10;
    printf("x = %d\n", x);
    x++;
    printf("x++: %d\n", x);
    x--;
    printf("x--: %d\n", x);
}

この書き方を後置インクリメントと呼びます。これらの演算子は、++x; --x; と記述することも可能で、これを前置インクリメントと呼びます。x++と++xは厳密には違いがあります。

op_5.c

int main() {
    int x = 10;
    int y = 10;

    printf("x = %d\n", x++); // x = 10
    printf("y = %d\n", ++y); // y = 11

    printf("x = %d, y = %d\n", x, y); // x = 11, y = 11

    return 0;
}

上記の例で、どちらも「変数の値に1を足す」という処理は同じですが、計算結果を代入するタイミングが異なります。 後置インクリメントは同じ行の処理 (printf) をしてから変数 (x) を更新するのに対し、前置インクリメントは変数 (y) を更新してから同じ行の処理 (printf) を実行します。前置インクリメントは値の更新が優先的に実行される、ということを覚えておきましょう。

一見ささいな違いに見えますが、このような小さな挙動の違いが大きなバグにつながる可能性もあります。プログラミングにおいて、言語の仕様をしっかりと理解することは非常に重要です。
