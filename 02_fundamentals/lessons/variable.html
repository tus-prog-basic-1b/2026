変数¶

プログラムでは様々なデータを扱います。このデータを格納しておく入れ物を**変数 (variable)**と言います。この講義では、変数の扱い方やデータを格納する方法を学びます。

変数の型¶

データには、数字や文字などの様々な種類 (型) があります。C言語がサポートしている代表的な型には以下のようなものがあり、型によって格納できるデータの種類やサイズが異なります。

  • int: 整数値 (4バイト/32bit幅)。
  • float: 小数値 (4バイト/32bit幅)。単精度浮動小数点実数、有効桁数約7桁
  • double: 小数値 (8バイト/64bit幅)。有効桁数約15桁
  • char: 文字 (1バイト/8bit幅)。英数字1字分

変数の宣言と代入¶

変数を使うためには、プログラムが扱う変数を使う前にあらかじめ名前をつける (宣言する) 必要があります。 C言語では、変数を宣言する時に、名前だけでなく、その変数が扱うデータの型も指定する必要があります。 これをまとめて、変数は「型 変数名;」というフォーマットで宣言します。

宣言した変数には、データを格納したり、取り出したりすることができます。 ここで、変数に値を入れる/格納することを「代入」と言い、「=」を使って左辺の変数に右辺の値を代入することができます。

ややこしいですが、プログラミングの世界では数学と異なり、「a = b」は「左辺 (a) と右辺 (b) が同じ」という意味ではありません。「左辺へ右辺を代入する」という意味になります。余談ですが、「左辺と右辺が同じ」ということをプログラムで表すには、「a == b」のように、イコールを2つ並べる必要があります。

それでは、変数の宣言と代入の例を見てみましょう。この例では、main関数の先頭（ブロックの先頭）にまとめて宣言し、その後で値を代入しています。ブロックとは、{ と } で括られた範囲のことです。

var_1.c

#include <stdio.h>

int main( ) {
        int i;                      /* 整数型変数 i の宣言 */
        i = 1;                          /* 宣言済みの i に代入 */
}

次の例のように、変数の宣言と同時に初期値を代入することもできます。初期値を設定することを「初期化」と言い、宣言後の代入とは区別されます。

var_2.c

#include <stdio.h>

int main( ) {
        int i = 1;                          /* 整数型変数 i の宣言と初期化を同時に行う */
}

同じ型の変数を複数宣言するときには、「型 変数名, 変数名, ... ,変数名;」と書くこともできます。

var_3.c

#include <stdio.h>

int main( ) {
    int i , j;           /* 整数型変数 i と j の宣言 */
    i = 1;
    j = 2;
}

複数の変数の宣言と初期化もまとめて行うことができます。 が、1つの行にたくさんの処理を書くとコードが読みにくくなるため、個人的にはあまりおすすめしません。

var_4.c

#include <stdio.h>

int main( ) {
    int i = 1, j = 2;           /* 整数型変数 i と j の宣言と初期化 */
}

指定子：変数の出力¶

これで変数にデータを保存できるようになりました。では、変数に保存したデータを表示するにはどうすれば良いでしょうか。 方法の1つが、hello worldプログラムでも出てきた printf (print format) 関数です。printfは直接入力した文字列だけでなく、変数も文字列としてプログラムの実行画面 (ターミナル) に表示することができます。 ひとまず、printfを使った例として、変数iの中身を出力するコードを見てみましょう。

var_5.c

#include <stdio.h>

int main( ) {
        int i;                      /* 整数型変数 i の宣言 */
        i = 1;                          /* i に代入 */
        printf( "%d\n" , i );
}

「%d」という、見慣れない記号が出てきました。これを指定子と呼びます。 printfで変数の中身を表示するには、変数の型に応じて異なる指定子を使う必要があります。

  • %d: 整数値（int）を10進数（decimal）で表示します
  • %f: 小数値（float）を実数で表示します
  • %c: 文字（char）を出力します

printfは、カンマで区切った前半部分と後半部分に分かれます。前半部分はターミナルに出力したい文字列 (""で囲った部分) を表しますが、この中に指定子を書きます。カンマの後ろの後半部分には、表示したい変数名を書きます。

複数の変数を表示したい場合は、文字列内に同じ数の指定子を書いて、その指定子に対応する変数を順にカンマを使って書いていきます。

var_6.c

#include <stdio.h>

int main( ) {
        int i = 1;                      /* 整数型変数 i の宣言と初期化 */
        float j = 1.5;                  /* 小数型変数 j の宣言と初期化 */
        char k = 'a';                   /* 文字型変数 k の宣言と初期化 */

        printf( "i = %d\n" , i );
        printf( "j = %f\n" , j );
        printf( "k = %c\n" , k );

    printf("i = %d\nj = %f\nk = %c\n", i, j, k);    /* 複数の指定子 */
}

数字を出力する場合、その桁数を指定することもできます。 例えば、二桁分の幅を確保した整数型を出力したいときは、

  • %2d

と書きます。これは出力する値を揃えたいときに用います。

var_7.c

#include <stdio.h>

int main( ) {
        int i = 1;
    int j = 10;
    int k = 100;

    printf("%2d", i);
    printf("%2d", j);
    printf("\n");
    printf("%3d\n%3d\n%3d\n", i, j, k);
}

変数の名付け方について¶

上記では、1文字だけの変数名を使っていますが、複数の文字を使っても構いません。 また、大文字も使うことができます。ただし、大文字と小文字は区別されるので注意して下さい。 アルファベットだけでなく _ （アンダースコア）も用いることができます。 2文字目以降は、数字も使うことができます。 変数名をつけるときは、 なるべくわかりやすい名前 をつけてあげましょう。（後日プログラムを見るときに役立ちます。）

int、if、return など、C言語のキーワードは変数名に使えません。 printf や main はキーワードではなく関数名です。この授業では、既存の関数名との混同を避けるため、変数には別の名前を付けましょう。

var_8.c

#include <stdio.h>

int main( ) {
        int x1 = 1;
        int x2 = 2;
    int ans = x1 * x2;

        printf("%d * %d = %d\n", x1, x2, ans);
}

参考¶

  • 関数内の通常のローカル変数は、宣言しただけでは決まった初期値を持ちません。値を読み取る前に、初期化または代入を行ってください。
  • 代入する値の型を確認しましょう。例えば、浮動小数点数を整数型の変数に代入すると型が変換され、小数部分が失われます。コンパイルできても、意図した値になるとは限りません。
  • 変数を宣言する場所は、古い C 言語では上の例のようにブロックの先頭に限られていました。 C99以降では、下の例のようにブロック内で処理の途中に宣言を書くこともできます。ただし、その変数を使う位置より前に宣言する必要があります。 C言語では一行のコメントであれば "//" という記号の後ろに書くことができます。

var_9.c

#include <stdio.h>

int main( ) {
        int i = 1;                      // 整数型変数 i の宣言と初期化
        printf( "i = %d\n" , i );

        float j = 1.5;                  // 小数型変数 j の宣言と初期化
        printf( "j = %f\n" , j );

        char k = 'a';                   // 文字型変数 k の宣言と初期化
        printf( "k = %c\n" , k );

    printf("i = %d\nj = %f\nk = %c\n", i, j, k);    // 複数の指定子
}
