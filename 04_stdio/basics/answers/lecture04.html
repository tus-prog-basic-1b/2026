第4回 文字コードと標準入出力の解答例¶

教材目次

基礎演習6・7の解答例である。演習6は文字コードと文字列の講義、演習7は標準入出力の講義に対応している。各コードはそれぞれ別のCファイルとして保存する。

文字コードは講義と同じくASCIIを前提とする。入力のある問題では、指定した形式と範囲の値を正しく入力するものとし、入力エラーへの対応は扱わない。

演習6 (1) 大文字と小文字の文字コードの値の差¶

exe06_1.c に保存する。

#include <stdio.h>

int main(void) {
    char big = 'A';
    char small = 'a';
    printf("'A' のコード: %d\n", big);
    printf("'a' のコード: %d\n", small);
    printf("差: %d\n", small - big);
    return 0;
}

出力例：

'A' のコード: 65
'a' のコード: 97
差: 32

文字を %d で出力すると、その文字の文字コードの値が表示される。ASCIIでは、同じ英字の小文字の値は大文字の値より32大きくなる。

演習6 (2) 大文字を小文字に変換¶

exe06_2.c に保存する。

#include <stdio.h>

int main(void) {
    char c1 = 'A';
    char c2 = 'C';
    c1 = c1 + ('a' - 'A');
    c2 = c2 + ('a' - 'A');
    printf("%c\n%c\n", c1, c2);
    return 0;
}

出力例：

a
c

(1) の差を加える。32 と直接書く代わりに 'a' - 'A' と書くと、何の差を加えているかが読み取りやすい。この例では変換対象が大文字であることを前提にしている。

演習6 (3) 小文字を大文字に変換¶

exe06_3.c に保存する。

#include <stdio.h>

int main(void) {
    char ch = 'f';
    ch = ch - ('a' - 'A');
    printf("%c\n", ch);
    return 0;
}

出力例：

F

小文字から大文字へ変換するときは差を引く。

演習7 名前と点数の入力¶

exe07.c に保存する。

#include <stdio.h>

int main(void) {
    char name[100];
    int score;
    scanf("%99s %d", name, &score);
    printf("名前：%s、点数：%d\n", name, score);
    return 0;
}

入力例：

Taro 85

出力例：

名前：Taro、点数：85

名前は文字列なので char 型の配列 name に %s で読み取る。配列の大きさは100なので、末尾の \0 の分を残して %99s で99文字までに制限する。文字列を受け取る配列名には & を付けないが、整数を受け取る score には & を付ける。

書式指定子と変数は左から順に対応する。この例では %99s が name、%d が score に対応する。入力の名前と点数は空白で区切る。
