第4回：Cプログラムのデバッグ入門（解答例）¶

問題へ

修正と確認の進め方¶

エラーや警告を読み、原因を調べて1箇所ずつ修正する。例えば、課題1に対しては以下のように警告を有効にしてコンパイルし、警告がなくなったら実行結果を仕様と比較する。

gcc -std=c11 -Wall -Wextra -pedantic -g bug01.c
./a.out

課題1：bug01.c¶

変数宣言の末尾に ; を付ける。エラーで示された行だけでなく、その直前の行も確認する。

#include <stdio.h>

int main(void)
{
    int year = 2026;
    printf("%d\n", year);
    return 0;
}

実行結果は次のとおり。

2026

課題2：bug02.c¶

scroe を、宣言した変数名 score に修正する。変数名の綴りは宣言と使用箇所で一致させる。

#include <stdio.h>

int main(void)
{
    int score = 80;
    printf("%d\n", score);
    return 0;
}

実行結果は次のとおり。

80

課題3：bug03.c¶

文字列を表す "A" を、1文字を表す文字定数 'A' に修正する。char 型の変数には文字を保存し、%c で表示する。

#include <stdio.h>

int main(void)
{
    char grade = 'A';
    printf("%c\n", grade);
    return 0;
}

実行結果は次のとおり。

A

課題4：bug04.c¶

printf の書式指定子を、整数 age には %d、文字 initial には %c に修正する。%s は文字列を表示する指定子である。

#include <stdio.h>

int main(void)
{
    int age = 18;
    char initial = 'K';

    printf("age = %d\n", age);
    printf("initial = %c\n", initial);
    return 0;
}

実行結果は次のとおり。

age = 18
initial = K

課題5：bug05.c¶

scanf の入力先を x から &x に修正する。&x は変数 x のアドレスを表し、scanf が読み取った整数を保存する場所を指定する。

#include <stdio.h>

int main(void)
{
    int x;

    scanf("%d", &x);
    printf("%d\n", x);
    return 0;
}

入力として 2026 を与えたときの出力は次のとおり。

2026

課題6：bug06.c¶

課題1〜5の要素を組み合わせた問題である。最初のエラーや警告から1箇所ずつ修正し、そのたびに再コンパイルする。

  • year の宣言末尾に ; を付ける。
  • mark に代入する "#" を文字定数 '#' にする。
  • yaer を宣言済みの変数名 year にする。
  • scanf の入力先を &input にする。
  • 最後の printf の書式を、文字と整数に対応する %c %d にする。
#include <stdio.h>

int main(void)
{
    int year = 2026;
    char mark = '#';
    int input;

    printf("%d\n", year);
    scanf("%d", &input);
    printf("%c %d\n", mark, input);
    return 0;
}

入力として 2026 を与えたときの出力は次のとおり。

2026
# 2026

完了時の確認¶

修正済みの bug01.c〜bug06.c がすべて作業場所にあり、それぞれ警告なくコンパイルでき、各課題の仕様を満たすことを確認する。 確認後はTAに報告し、主に課題6の bug06.c の修正内容と実行結果を確認してもらう。
