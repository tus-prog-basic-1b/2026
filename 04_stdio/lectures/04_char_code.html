文字コードと文字列¶

コンピュータは 0 と 1 の組み合わせで処理を行うため、人間の扱う文字をそのまま理解することはできません。 各文字に数値を割り当て、コンピュータが理解できるようにしたものを「文字コード」と呼びます。 このとき割り当てられた値はコードポイント (code point) とも呼びます。

文字コードには様々な種類がありますが、本資料ではその 1 つである ASCII を扱います。 ASCII の対応表は資料には載せないので、インターネットを参照してください。

プログラミングでの扱い¶

プログラミングでは、文字コードを使って文字を数値として扱います。そのため、数値を文字として扱うこともできます。 例えば C 言語では、文字を整数指定子 %d で出力すると文字コードの値が表示されます。

#include <stdio.h>

int main(){
    char ch = 'A';
    int num = 66;

    printf("%d\n", ch);
    printf("%c\n", num);
}

上記では、ch は 'A' ですが、%d を指定しているため 65 が出力されます。 num は 66 ですが、%c を指定すると文字 'B' が出力されます。

文字コードの利用¶

文字コードを利用することで様々な処理が可能です。以下に例を示します。

文字の操作¶

文字に対して計算を行い、別の文字に変換できます。

#include <stdio.h>

int main(){
    char ch = 'A';
    ch += 2;
    printf("%c\n", ch);
}

'A' に対応する数値 65 に 2 を加算し 67 となり、結果は 'C' となります。

文字列¶

これまで printf("Hello\n"); のように、二重引用符 " " で囲んで表示してきたものを「文字列」と呼びます。文字列は、文字を順に並べたものです。C言語では、文字列の末尾に終端文字 '\0' を付けて、文字列の終わりを表します。'\0' は文字コードの値が 0 の文字です。

例えば、文字列 "Hello" は、次の6つの文字が順に並んだものです。

文字 'H' 'e' 'l' 'l' 'o' '\0'
文字コード 72 101 108 108 111 0

文字と文字列の違い¶

'A' のように一重引用符 ' ' で囲んだものは1文字です。char 型の変数に入れ、%c で表示します。 一方、"A" のように二重引用符 " " で囲んだものは文字列で、'A' と '\0' の2文字が並んだものです。文字列は %s で表示します。 見た目が似ていても別のものなので、char 型の変数に "A" を代入したり、char 型の変数を %s で表示したりすると、正しく動きません。

文字列を変数に入れる¶

文字列は複数の文字が並んだものなので、1文字しか入らない char 型の変数には入りません。文字列を入れるには、char 型の配列を使います。ここでは配列を「複数の文字を入れる場所」として使い、配列の詳しい操作は第9回で学びます。

#include <stdio.h>

int main(){
    char c = 'A';
    char word[6] = "Hello";

    printf("%c\n", c);
    printf("%s\n", word);
}

char word[6] は6文字分の場所を用意します。"Hello" は5文字ですが、末尾の '\0' の分も必要なので、6文字分の場所を用意します。文字列を表示するときは、%s に配列名 word を渡します。 上記を実行すると、1行目に A、2行目に Hello が表示されます。
