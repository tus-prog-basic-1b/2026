第5回 条件分岐の解答例¶

教材目次

基礎演習8・9と、演習8の「時間が余ったら」の解答例である。演習8はswitch文の講義、演習9はif文の講義に対応している。各コードはそれぞれ別のCファイルとして保存する。

演習8 干支判定¶

exe08.c に保存する。

#include <stdio.h>

int main(void) {
    int year = 2025;

    switch ((year + 8) % 12) {
        case 0:
            printf("%d: Rat\n", year);
            break;
        case 1:
            printf("%d: Ox\n", year);
            break;
        case 2:
            printf("%d: Tiger\n", year);
            break;
        case 3:
            printf("%d: Rabbit\n", year);
            break;
        case 4:
            printf("%d: Dragon\n", year);
            break;
        case 5:
            printf("%d: Snake\n", year);
            break;
        case 6:
            printf("%d: Horse\n", year);
            break;
        case 7:
            printf("%d: Goat\n", year);
            break;
        case 8:
            printf("%d: Monkey\n", year);
            break;
        case 9:
            printf("%d: Rooster\n", year);
            break;
        case 10:
            printf("%d: Dog\n", year);
            break;
        case 11:
            printf("%d: Pig\n", year);
            break;
    }
    return 0;
}

出力例：

2025: Snake

十二支は12年で一巡する。西暦4年は子年（Rat）なので、西暦に8を足して12で割った余り (year + 8) % 12 は、ヒントの表の左から数えた位置（子が0、亥が11）になる。4に8を足すと12の倍数になり、余りが0になる。2025年は (2025 + 8) % 12 が5になり、巳（Snake）である。

余りは0から11のどれかになるので、その値ごとに処理を分けるには switch文が適している。各 case の最後には break を書く。

year を2020（Rat）や2026（Horse）などに変えて、ほかの年でも正しく表示されることを確かめるとよい。

演習8 時間が余ったら¶

問題ではファイル名を指定していないので、ここでは exe08_2.c、exe08_3.c とする。

十干十二支¶

exe08_2.c に保存する。

#include <stdio.h>

int main(void) {
    int year = 2025;

    printf("%d: ", year);

    switch ((year + 6) % 10) {
        case 0: printf("甲"); break;
        case 1: printf("乙"); break;
        case 2: printf("丙"); break;
        case 3: printf("丁"); break;
        case 4: printf("戊"); break;
        case 5: printf("己"); break;
        case 6: printf("庚"); break;
        case 7: printf("辛"); break;
        case 8: printf("壬"); break;
        case 9: printf("癸"); break;
    }

    switch ((year + 8) % 12) {
        case 0: printf("子"); break;
        case 1: printf("丑"); break;
        case 2: printf("寅"); break;
        case 3: printf("卯"); break;
        case 4: printf("辰"); break;
        case 5: printf("巳"); break;
        case 6: printf("午"); break;
        case 7: printf("未"); break;
        case 8: printf("申"); break;
        case 9: printf("酉"); break;
        case 10: printf("戌"); break;
        case 11: printf("亥"); break;
    }

    printf("\n");
    return 0;
}

出力例：

2025: 乙巳

十干は10年、十二支は12年で一巡する。西暦4年は甲子（きのえね）の年なので、十干は (year + 6) % 10、十二支は (year + 8) % 12 で、それぞれ甲・子を0とした位置が求まる。4に6を足すと10の倍数に、4に8を足すと12の倍数になるためである。2つの switch文で十干と十二支を順に表示し、最後に改行する。

各 case は処理が1つだけなので、1行にまとめて書いている。1984年（甲子）、2024年（甲辰）、2026年（丙午）などでも確かめるとよい。

年齢¶

exe08_3.c に保存する。

#include <stdio.h>

int main(void) {
    int birth_y, birth_m, birth_d;
    int y, m, d;
    int age;

    printf("生年月日を入力してください（年 月 日）: ");
    scanf("%d %d %d", &birth_y, &birth_m, &birth_d);
    printf("日付を入力してください（年 月 日）: ");
    scanf("%d %d %d", &y, &m, &d);

    age = y - birth_y;
    if (m < birth_m || (m == birth_m && d < birth_d)) {
        age = age - 1;
    }

    printf("%d年%d月%d日の時点で%d才です。\n", y, m, d, age);
    return 0;
}

実行例（2006 4 15 と 2025 10 19 はキーボードから入力した値）：

生年月日を入力してください（年 月 日）: 2006 4 15
日付を入力してください（年 月 日）: 2025 10 19
2025年10月19日の時点で19才です。

まず年の差を年齢とし、その年の誕生日をまだ迎えていなければ1を引く。誕生日をまだ迎えていないのは、「月が誕生月より前」または「誕生月で、日が誕生日より前」のときで、これを || と && で1つの条件式にしている。

誕生日の当日（例：2025 4 15）は年齢が1つ増え、その前日（2025 4 14）は増えないことを確かめるとよい。入力する年月日は、いずれも実在する日付とし、年齢を求める日付は生年月日以降とする。2月29日生まれの場合、平年には3月1日に年齢が1つ増える。

演習9 判別式¶

exe09.c に保存する。

#include <stdio.h>

int main(void) {
    int a = 3;
    int b = 5;
    int c = 7;
    int d = b * b - 4 * a * c;

    if (d > 0) {
        printf("2\n");
    } else if (d == 0) {
        printf("1\n");
    } else {
        printf("0\n");
    }
    return 0;
}

出力例：

0

二次関数 y = ax² + bx + c のグラフと x 軸との交点の数は、判別式 D = b² − 4ac の符号で決まる。D が正なら2個、0なら1個（x 軸に接する）、負なら0個である。ここでは a が0でない（二次関数である）ことを前提にしている。

判別式の値を変数 d に求め、正・0・負の3通りを if、else if、else で判定する。範囲（正か負か）で分ける条件なので、switch文ではなく if文を使う。

a = 3、b = 5、c = 7 のとき、D = 25 − 84 = −59 で負なので、0 が表示される。ほかの分岐も確かめるには、例えば次の値を使う。

a b c D 出力
1 2 1 0 1
1 0 -1 4 2
3 5 7 -59 0
