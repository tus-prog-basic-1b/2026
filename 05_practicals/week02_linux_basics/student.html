第2回：Linuxでのファイル操作¶

課題¶

配布された starter/generate_records.c を使い、データ生成プログラムとその生成結果を次の構成に整理してください。

week02/
└── exercise/
    ├── src/
    │   └── generate_records.c
    ├── bin/
    │   └── generate_records
    └── data/
        ├── records.txt
        └── records_sorted.txt

完成までに、次の要件をすべて満たしてください。

  1. ホームディレクトリの下に作業ディレクトリ prog-basic-b1/week02/exercise/ を作成
  2. generate_records.c を作業ディレクトリへコピー
  3. 実行ファイル名を指定せずにコンパイルし、作成されたプログラムの出力を確認
  4. 実行ファイル名を generate_records に変更し、ソースファイルと実行ファイルをそれぞれ src/ と bin/ に移動（ディレクトリは新たに作成すること）
  5. 整理した実行ファイルの標準出力を data/records.txt に保存
  6. records.txt の行数を確認
  7. records.txt を昇順に並べ替え、その結果を data/records_sorted.txt に保存

配布ファイルについての補足¶

配布ファイル (week02_linux_basics-exercises.zip) をダウンロードしたら、WindowsのフォルダーアプリからLinuxの作業ディレクトリへ手動で移動させ、解凍する。作業ディレクトリの絶対パスは、Windows側からはおおむね以下のように表示される。 

¥¥wsl.localhost¥Ubuntu¥home¥<ユーザー名>¥prog-basic-b1¥week02¥exercise

もしくは、Linux側のターミナルで wget や curl コマンドを利用することで、直接ダウンロードもできる。その場合、 unzip コマンドでファイルを解凍すること。各種コマンドは apt install <コマンド名> でインストールできる。

$ wget https://tus-prog-basic-1b.github.io/2026/downloads/week02_linux_basics-exercises.zip
$ unzip week02_linux_basics-exercises.zip 
Archive:  week02_linux_basics-exercises.zip
  inflating: starter/generate_records.c 

$ curl -O https://tus-prog-basic-1b.github.io/2026/downloads/week02_linux_basics-exercises.zip
$ unzip week02_linux_basics-exercises.zip 
Archive:  week02_linux_basics-exercises.zip
  inflating: starter/generate_records.c

完了時に確認するファイル¶

  • src/generate_records.c
  • data/records.txt
  • data/records_sorted.txt

演習の最後に、上記のファイルとディレクトリ構成を作業場所で確認してください。
