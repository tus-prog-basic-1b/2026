第6回 繰り返しの解答例¶

教材目次

基礎演習10・11の解答例である（(3) 以降は「時間が余ったら」の問題）。演習10は繰り返し文の講義、演習11は繰り返し文 × if 文の講義に対応している。各コードはそれぞれ別のCファイルとして保存する。

演習10 (1) 3の倍数を出力する¶

exe10_1.c に保存する。

#include <stdio.h>

int main(void) {
    for (int i = 3; i <= 30; i += 3) {
        printf("%d\n", i);
    }
    return 0;
}

出力例：

3
6
9
（中略）
27
30

更新式を i += 3 とすることで、3から始めて3ずつ増やしながら繰り返す。i % 3 == 0 で判定する方法もあるが、3の倍数だけを順に作れる場合は、更新式を工夫すると繰り返しの回数を減らせる。

演習10 (2) 長方形を出力する¶

exe10_2.c に保存する。

#include <stdio.h>

int main(void) {
    for (int i = 0; i < 4; i++) {
        for (int j = 0; j < 10; j++) {
            printf("#");
        }
        printf("\n");
    }
    return 0;
}

出力例：

##########
##########
##########
##########

外側の繰り返しが行（4行）、内側の繰り返しが1行の中の文字（10文字）を担当する。1行分の # を出し終えたら、外側の繰り返しの中で改行する。

演習10 (3) 九九表¶

exe10_3.c に保存する。

#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 9; i++) {
        for (int j = 1; j <= 9; j++) {
            printf("%2d ", i * j);
        }
        printf("\n");
    }
    return 0;
}

出力例：

 1  2  3  4  5  6  7  8  9 
 2  4  6  8 10 12 14 16 18 
（中略）
 9 18 27 36 45 54 63 72 81

外側の i が段、内側の j が掛ける数を表す。%2d は整数を2文字分の幅で右にそろえて表示する指定子で、その後ろに空白を1つ出力して区切ることで、桁がそろう。

演習10 (4) 電卓メニュー¶

exe10_4.c に保存する。

#include <stdio.h>

int main(void) {
    int choice, a, b;
    do {
        printf("===== 電卓メニュー =====\n");
        printf("1) 足し算\n2) 引き算\n3) 掛け算\n0) 終了\n");
        printf("選択してください: ");
        scanf("%d", &choice);
        if (choice == 1) {
            scanf("%d %d", &a, &b);
            printf("%d + %d = %d\n", a, b, a + b);
        } else if (choice == 2) {
            scanf("%d %d", &a, &b);
            printf("%d - %d = %d\n", a, b, a - b);
        } else if (choice == 3) {
            scanf("%d %d", &a, &b);
            printf("%d * %d = %d\n", a, b, a * b);
        }
    } while (choice != 0);
    return 0;
}

実行例（3、4 5、0 はキーボードから入力した値）：

===== 電卓メニュー =====
1) 足し算
2) 引き算
3) 掛け算
0) 終了
選択してください: 3
4 5
4 * 5 = 20
===== 電卓メニュー =====
1) 足し算
2) 引き算
3) 掛け算
0) 終了
選択してください: 0

メニューは必ず1回表示するので、継続条件式を処理の後で判定する do-while文を使う。繰り返しの中では、入力された番号に応じて if・else if で処理を切り替え、0 が入力されたら choice != 0 が偽になって繰り返しを終える。0〜3以外の整数ではどの分岐も実行せず、メニューを再表示する。

演習10 (5) フィボナッチ数列¶

exe10_5.c に保存する。

#include <stdio.h>

int main(void) {
    int limit = 20;
    int a = 0, b = 1;
    while (a <= limit) {
        printf("%d ", a);
        int next = a + b;
        a = b;
        b = next;
    }
    printf("\n");
    return 0;
}

出力例：

0 1 1 2 3 5 8 13

a に現在の項、b に次の項を入れておき、表示した後で a と b を1つずつ先へ進める。値が limit（20）を超えたら終えるので、回数ではなく値で終わりを決める while文を使っている。ループ後に改行を出力する。

演習10 (6) 三角形を出力する¶

exe10_6.c に保存する。

#include <stdio.h>

int main(void) {
    int N = 5;
    for (int i = 1; i <= N; i++) {
        for (int j = 1; j <= i; j++) {
            printf("*");
        }
        printf("\n");
    }
    return 0;
}

出力例：

*
**
***
****
*****

内側の繰り返しの継続条件式を j <= i とすることで、i 行目には i 個の * が並ぶ。(2) の長方形と違い、行によって内側の繰り返しの回数が変わる。

演習11 (1) 条件に合う数を出力する¶

exe11_1.c に保存する。

#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 50; i++) {
        if (i % 3 == 0 && i % 9 != 0) {
            printf("%d\n", i);
        }
    }
    return 0;
}

出力例：

3
6
12
15
（中略）
42
48

if文の条件を i % 3 == 0 && i % 9 != 0 とすることで、3の倍数で、かつ9の倍数ではないときだけ表示される。

演習11 (2) 入力された数を調べる¶

exe11_2.c に保存する。

#include <stdio.h>

int main(void) {
    int x;
    int count = 0;
    int max = 0;

    printf("正の整数を入力してください（0で終了）: ");
    scanf("%d", &x);
    while (x != 0) {
        if (x > 0) {
            if (x % 2 == 1) {
                count++;
            }
            if (x > max) {
                max = x;
            }
        }
        scanf("%d", &x);
    }
    printf("奇数の個数: %d\n", count);
    printf("最大値: %d\n", max);
    return 0;
}

実行例（3、8、-5、11、4、0 はキーボードから入力した値）：

正の整数を入力してください（0で終了）: 3
8
-5
11
4
0
奇数の個数: 2
最大値: 11

継続条件式 x != 0 により、0 が入力されるまで読み取りを繰り返す。正の数のときだけ、奇数なら count を1増やし、それまでの最大値より大きければ max を更新する。最大値は、正の数だけを扱うので、最初の値を0にしている。正の整数が1つも入力されなかった場合は、仕様に従い、奇数の個数も最大値も初期値の0を表示する。

演習11 (3) 素数を列挙する¶

exe11_3.c に保存する。

#include <stdio.h>

int main(void) {
    for (int n = 2; n <= 100; n++) {
        int is_prime = 1;
        for (int d = 2; d < n; d++) {
            if (n % d == 0) {
                is_prime = 0;
                break;
            }
        }
        if (is_prime == 1) {
            printf("%d\n", n);
        }
    }
    return 0;
}

出力例：

2
3
5
7
（中略）
89
97

外側の n が調べる数、内側の d が割る数である。割り切れる d が1つでも見つかったら素数ではないので、is_prime を0にして break で内側の繰り返しを抜ける。内側の繰り返しを終えた後も is_prime が1なら、n は素数である。

演習11 (4) コラッツ列の長さ¶

exe11_4.c に保存する。

#include <stdio.h>

int main(void) {
    int N = 10;
    int max_len = 0, max_x = 1;
    for (int x = 1; x <= N; x++) {
        int n = x, len = 1;
        while (n != 1) {
            if (n % 2 == 0) {
                n = n / 2;
            } else {
                n = 3 * n + 1;
            }
            len++;
        }
        if (len > max_len) {
            max_len = len;
            max_x = x;
        }
    }
    printf("最長は %d (長さ %d)\n", max_x, max_len);
    return 0;
}

出力例：

最長は 9 (長さ 20)

外側の for文で1〜N の数 x を順に調べ、内側の while文で、n が1になるまでコラッツの規則を繰り返しながら長さを数える。回数があらかじめ決まっていないので、内側には while文を使う。長さがそれまでの最長より長ければ、その数と長さを記録する。
