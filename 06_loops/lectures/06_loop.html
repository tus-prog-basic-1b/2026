繰り返し文¶

同じ処理を繰り返す制御構造を「繰り返し文」と呼びます。 繰り返し文を使うことで、同じことを何度も記述する手間を省き、効率的でエラーの少ないプログラムを書くことができます。

序論¶

例として 210 の計算を行うプログラムを考えます。

繰り返し文を使わずに書くと：

#include <stdio.h>

int main(void){
    int n = 1;
    n = n * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2 * 2;
    printf("%d\n", n);
    return 0;
}

繰り返し文を使うと簡潔になります：

#include <stdio.h>

int main(void){
    int n = 1;
    for(int i = 0; i < 10; i++){
        n = n * 2;
    }
    printf("%d\n", n);
    return 0;
}

for文¶

「for文」では、繰り返しを続ける条件（継続条件式）と、その条件に使う変数の準備と更新方法を、まとめて書きます。これにより、特定の条件のもとで処理を繰り返す制御を記述できます。

構文¶

for(変数の初期化; 継続条件式; 更新式) {
    処理
}

処理の流れ¶

  1. 変数の初期化を、最初に1回だけ実行する。
  2. 継続条件式を判定する。真なら手順3へ進み、偽なら for文を終了する。
  3. { } 内の処理を実行する。
  4. 更新式を実行し、手順2に戻る。

例：210 を計算し出力する¶

#include <stdio.h>

int main(void){
    int n = 1;
    for(int i = 0; i < 10; i++){
        n = n * 2;
    }
    printf("%d\n", n);
    return 0;
}

この例では、変数の初期化が int i = 0、継続条件式が i < 10、更新式が i++ です。i が 0 から 9 までの間、{ } 内の処理が10回繰り返されます。

while文¶

「while文」は、条件を満たしている間、処理を繰り返します。

構文¶

while(継続条件式) {
    処理
}

継続条件式の書き方は、if文の条件と同じです。

処理の流れ¶

  1. 継続条件式を判定する。真なら手順2へ進み、偽なら while文を終了する。
  2. { } 内の処理を実行し、手順1に戻る。

処理の前に条件を判定するため、最初の判定で偽なら、{ } 内の処理は一度も実行しません。

例：2以上10以下の偶数を出力する¶

#include <stdio.h>

int main(void){
    int n = 2;
    while(n <= 10){
        printf("%d\n", n);
        n = n + 2;
    }
    return 0;
}

while文の特徴¶

上の例は、for文を使っても書くことができます。

#include <stdio.h>

int main(void){
    for(int n = 2; n <= 10; n = n + 2){
        printf("%d\n", n);
    }
    return 0;
}

while文の丸括弧内には、継続条件式だけを書きます。for文でも入力値などによる継続条件を書けますが、回数や更新方法が決まっている場合は for文、入力値などの条件を中心に繰り返す場合は while文を使うと、意図を表しやすくなります。

例えば、正の数が入力されるまで入力を繰り返すプログラムは、while文で次のように書けます。

#include <stdio.h>

int main(void){
    int n;
    printf("正の数を入力してください: ");
    scanf("%d", &n);
    while(n <= 0){
        printf("正の数を入力してください: ");
        scanf("%d", &n);
    }

    printf("入力された値: %d\n", n);
    return 0;
}

何回目の入力で正の数が入力されるかは、事前には分かりません。このように、回数ではなくキーボードから入力された値によって繰り返しを終えるかどうかが決まる場合は、while文が適しています。

ただし、while文は最初に継続条件式を判定するため、判定の前に n に値が入っている必要があります。そのため、このプログラムでは、ループの前とループの中の2か所に同じ入力処理を書いています。

do-while文¶

「do-while文」は、while文とほぼ同じですが、必ず1回は処理を実行した上で、継続条件式の判定と繰り返しを行います。「一度は必ず実行したい処理」があるときに効果的です。

構文¶

do {
    処理
} while (継続条件式);

例1：正の数を入力させる（do-while版）¶

#include <stdio.h>

int main(void){
    int n;
    do {
        printf("正の数を入力してください: ");
        scanf("%d", &n);
    } while(n <= 0);

    printf("入力された値: %d\n", n);
    return 0;
}

while文で書いたプログラムでは、ループの前とループの中に同じ入力処理を書く必要がありました。do-while文では、先に { } 内の処理を実行してから継続条件式を判定するため、入力処理を1か所にまとめて書けます。

例2：電卓メニュー¶

#include <stdio.h>

int main(void){
    int choice;    // ユーザの選択
    int a, b;      // 計算用の入力値

    do {
        // 電卓メニュー表示
        printf("===== 電卓メニュー =====\n");
        printf("1) 足し算\n");
        printf("2) 引き算\n");
        printf("0) 終了\n");
        printf("選択してください: ");
        scanf("%d", &choice);

        if(choice == 1){
            printf("2つの整数を入力してください: ");
            scanf("%d %d", &a, &b);
            printf("%d + %d = %d\n\n", a, b, a + b);
        }
        else if(choice == 2){
            printf("2つの整数を入力してください: ");
            scanf("%d %d", &a, &b);
            printf("%d - %d = %d\n\n", a, b, a - b);
        }
        else if(choice != 0){
            printf("不正な入力です。もう一度選んでください。\n\n");
        }

    } while(choice != 0);  // 0でない限り繰り返す（0なら終了）

    printf("プログラムを終了します。\n");
    return 0;
}

例2のように、繰り返しの中で if文を使うと、入力に応じて処理を切り替えるなど、より複雑な処理を記述できます。繰り返しと if文の組み合わせ方は、次のページ「繰り返し文 × if 文」で詳しく学びます。

多重ループ¶

繰り返し文の中に繰り返し文を入れる構造を「多重ループ」と呼びます。 多重ループを使うと、ある繰り返しの1回ごとに、別の繰り返しをまるごと行えます。これにより、1つの繰り返し文だけでは自然に書けない処理を記述できます。例えば、表やマス目のように、行と列の組み合わせごとに処理を行う場合に使います。

例：縦3×横5の「O」を並べて出力する¶

#include <stdio.h>

int main(void){
    for(int i = 0; i < 3; i++){
        for(int j = 0; j < 5; j++){
            printf("O");
        }
        printf("\n");
    }
    return 0;
}
