第7回：総合演習（追加問題）¶

第2回〜第6回の内容を使う追加問題 (13)〜(24) に取り組む。 プログラムは作業ディレクトリ ~/prog-basic-b1/week07/exercise に、問題番号に合わせて comp13.c のような名前で保存する。

(13) 大きい方の値¶

2つの整数を入力し、大きい方の値を表示しなさい。三項演算子を使うこと。2つの値が等しいときは、その値を表示すればよい。

実行例（3 8 はキーボードから入力した値）

$ ./a.out
2つの整数を入力してください: 3 8
大きい方は 8
$

(14) 3つの値の一部を使って10を作れるか¶

仕様

  • 3 個の整数 A B C を標準入力で受け取る。
  • これらのうち、1 個以上の好きな組合せを選んで合計を計算できる。
  • どれか 1 つ以上を選んだとき、その合計がちょうど 10 になるような選び方が存在するかどうかを判定しなさい。
  • 10 を作れる場合は Yes、作れない場合は No と 1 行で出力しなさい。

プログラム（ひな形）

#include <stdio.h>

int main(void) {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);

    /* 7通りの組合せのどれかが10になるか調べる */

    return 0;
}

実行例（3 7 5、4 2 1、10 3 3 はキーボードから入力した値）

$ ./a.out
3 7 5
Yes
$ ./a.out
4 2 1
No
$ ./a.out
10 3 3
Yes
$

(16) 漸化式¶

次の漸化式で表される数列の、第1項から第5項までを1行に1つずつ出力しなさい。

x1 = 2、xn = xn-1 × 3 + 1（n ≥ 2）

実行例

$ ./a.out
2
7
22
67
202
$

(17) 枠付き長方形¶

縦4×横10の長方形を、外枠を #、内側を空白にして出力しなさい。多重ループと if文を使うこと。

実行例

$ ./a.out
##########
#        #
#        #
##########
$

(18) 複数入力版 FizzBuzz¶

仕様

  • 標準入力で 3 つの整数 X Y N をこの順に受け取る。
  • X と Y は1以上とする。
  • 1 から N までの整数について、以下のルールに従って 1 行ずつ出力しなさい。
  • その数が X の倍数かつ Y の倍数のとき：FizzBuzz と出力
  • その数が X の倍数のとき：Fizz と出力
  • その数が Y の倍数のとき：Buzz と出力
  • 上記のどれにも当てはまらないとき：その数値をそのまま出力

プログラム（ひな形）

#include <stdio.h>

int main(void) {
    int X, Y, N;
    /* ここに入力 */
    for (int i = 1; i <= N; i++) {
        /* ここに条件分岐を書いて出力する */
    }
    return 0;
}

実行例（3 5 10 はキーボードから入力した値）

$ ./a.out
3 5 10
1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
$

X、Y を変えても正しく動くか確かめること。例えば 2 3 7 を入力すると、6 のときに FizzBuzz と出力される。

(19) 5から1までの総和¶

次のプログラムには誤りが含まれている。入力して保存し、仕様どおりに動くように直しなさい。直す前に期待する結果を決め、1か所ずつ修正してコンパイル・実行すること。デバッグの進め方も参照すること。

仕様：N=5 から 1 までの総和を表示する。

#include <stdio.h>

int main(void) {
    int N = 5;
    int s = 0;

    for (int i = N; i > 1; i--) {
        s = s + i;
    }
    printf("%d\n", s);
    return 0;
}

正しい実行例

$ ./a.out
15
$

(20) N以下の偶数¶

次のプログラムには誤りが含まれている。入力して保存し、仕様どおりに動くように直しなさい。直す前に期待する結果を決め、1か所ずつ修正してコンパイル・実行すること。デバッグの進め方も参照すること。

仕様：N=5 として、N 以下の正の偶数を小さい順に1行に1つずつ表示する。

#include <stdio.h>

int main(void) {
    int N = 5;
    int i;

    while (i <= N) {
        printf("%d\n", i);
        i += 2;
    }
    return 0;
}

正しい実行例

$ ./a.out
2
4
$

(21) 0 が入力されるまで繰り返す¶

次のプログラムには誤りが含まれている。入力して保存し、仕様どおりに動くように直しなさい。直す前に期待する結果を決め、1か所ずつ修正してコンパイル・実行すること。デバッグの進め方も参照すること。

仕様：整数を入力するたびに「（入力した値）が選ばれました」と表示し、0 が入力されるまでこれを繰り返す。0 が入力されたら「終了します」と表示して終了する。

#include <stdio.h>

int main(void) {
    int choice = 0;

    do {
        printf("番号を入力してください（0で終了）: ");
        scanf("%d", &choice);
        printf("%d が選ばれました\n", choice);
    } while (choice = 0);
    printf("終了します\n");
    return 0;
}

正しい実行例（1、2、0 はキーボードから入力した値）

$ ./a.out
番号を入力してください（0で終了）: 1
1 が選ばれました
番号を入力してください（0で終了）: 2
2 が選ばれました
番号を入力してください（0で終了）: 0
0 が選ばれました
終了します
$

(22) Good / Bad / Perfect!¶

1 から 30 までの整数を、空白で区切って1行に出力しなさい。ただし、3の倍数のときは「Good」、5の倍数のときは「Bad」、3と5の両方の倍数のときは「Perfect!」を、数値の代わりに出力すること。

実行例

$ ./a.out
1 2 Good 4 Bad Good 7 8 Good Bad 11 Good 13 14 Perfect! 16 17 Good 19 Bad Good 22 23 Good Bad 26 Good 28 29 Perfect!
$

(23) ひし形¶

N=3 として、次のようなひし形を * で出力しなさい。上半分（1〜N行目）と下半分に分けて考えるとよい。

実行例

$ ./a.out
  *
 ***
*****
 ***
  *
$

(24) 表形式 FizzBuzz¶

4行×5列の表に、1 から順に値を入れて FizzBuzz を表示しなさい。表示は次の略記を使い、桁をそろえること：F=Fizz、B=Buzz、FB=FizzBuzz（3の倍数が F、5の倍数が B、両方の倍数が FB）。 (11) と (18) のプログラムを組み合わせて考えるとよい。

実行例

$ ./a.out
 1  2  F  4  B
 F  7  8  F  B
11  F 13 14 FB
16 17  F 19  B
$
