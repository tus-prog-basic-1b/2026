問題へ

(1)〜(7) の解答例である。各コードは問題番号に合わせた別のCファイルとして保存する（(2)、(5) を除く）。解答例は一例であり、仕様を満たしていれば別の書き方でもよい。

(1) 文字列を出力する¶

comp01.c に保存する。

#include <stdio.h>

int main(void) {
    printf("C programming\n");
    printf("Week 07 review\n");
    return 0;
}

(2) Terminalでコンパイルして実行する¶

$ pwd

pwd のユーザ名や ls の一覧は環境や作成済みのファイルによって異なる。

(3) 四則演算¶

comp03.c に保存する。

#include <stdio.h>

int main(void) {
    int a = 15;
    int b = 4;

    printf("和=%d\n", a + b);
    printf("差=%d\n", a - b);
    printf("積=%d\n", a * b);
    printf("商=%d\n", a / b);
    printf("余り=%d\n", a % b);
    return 0;
}

出力例：

和=19
差=11
積=60
商=3
余り=3

整数どうしの割り算 a / b は、小数点以下が切り捨てられて 3 になる。余りは % で求める。

(4) 変数の値を更新する¶

comp04.c に保存する。

#include <stdio.h>

int main(void) {
    int x = 10;

    printf("%d\n", x);
    x = x + 3;
    printf("%d\n", x);
    x = x * 2;
    printf("%d\n", x);
    return 0;
}

(5) grepでファイルの内容を調べる¶

$ wc -l fizzbuzz.txt
30 fizzbuzz.txt
$ grep -c "Fizz" fizzbuzz.txt
10
$ grep -c "^Fizz$" fizzbuzz.txt
8
$ grep -n "FizzBuzz" fizzbuzz.txt
15:FizzBuzz
30:FizzBuzz
$ grep -v "zz" fizzbuzz.txt | wc -l
16
  • (a) 1〜30 の各整数について1行ずつ出力するので、30 行。
  • (b) Fizz を 含む 行を数えるので、Fizz の行（8行）に加えて FizzBuzz の行（15、30 の2行）も数えられ、10 になる。3 の倍数の個数と同じである。
  • (c) ^ は行頭、$ は行末を表すので、^Fizz$ は行全体がちょうど Fizz である行だけに一致し、8 になる。
  • (d) -n で行番号が付く。1〜30 を1行ずつ出力しているので、行番号はその行の整数と同じになる。
  • (e) -v は一致 しない 行を表示する。Fizz・Buzz・FizzBuzz の行はどれも zz を含むので、数値の行だけが残る。3 の倍数（10個）と 5 の倍数（6個）のうち、15 の倍数（2個）は両方に含まれるので、30 − (10 + 6 − 2) = 16 行になる。

(6) 文字コード：数字の文字を数値に変える¶

comp06.c に保存する。

#include <stdio.h>

int main(void) {
    char c;

    printf("数字を1文字入力してください: ");
    scanf("%c", &c);
    printf("文字コード=%d\n", c);
    if (c >= '0' && c <= '9') {
        int n = c - '0';
        printf("%d の2倍は %d\n", n, n * 2);
    } else {
        printf("数字ではありません\n");
    }
    return 0;
}

出力例：

数字を1文字入力してください: 7
文字コード=55
7 の2倍は 14

'0'〜'9' の文字コードの値は1ずつ増えるので、c - '0' で、文字 '7' から数値 7 が求まる。'7' の文字コードの値（55）をそのまま2倍しないように注意する。数字かどうかは、c >= '0' && c <= '9' で判定する。

%c は文字を、%d はその文字コードの値を10進数で表示する。文字 0 のコードは48で数値は0、文字 9 のコードは57で数値は9になる（実習環境）。

(7) デバッグ：2つの整数の平均¶

comp07.c に保存する。

#include <stdio.h>

int main(void) {
    int a, b;
    float avg;

    scanf("%d %d", &a, &b);
    avg = (a + b) / 2.0;
    printf("平均 %f\n", avg);
    return 0;
}

-Wall -Wextra を付けてコンパイルすると、主に次の警告が出る（gcc の場合）。

  • scanf の行：format '%d' expects argument of type 'int *', but argument 2 has type 'int' → a の前に & がない。
  • printf の行：format '%d' expects argument of type 'int', but argument 2 has type 'double' → 小数を表示するので %f にする。

警告をなくしても、(a + b) / 2 は整数どうしの割り算なので、3 と 4 の平均が 3.000000 になる。2.0 で割ると小数の割り算になり、3.500000 になる。
