関数は「処理のまとまり」を作るための基本構文です。 以下の問題では、スケルトンコードを完成させましょう。

1. 関数の定義と呼び出し¶

ファイル名：exe10_f_1.c

要件： 「Hello!」「World!」を出力する関数 hello() を定義し、 メイン関数から呼び出して次のように出力せよ。

出力例：

START
Hello!
World!
END

#include <stdio.h>

// ここに関数定義を書く

int main(void){
    printf("START\n");
    // hello関数を呼び出す
    printf("END\n");
}
