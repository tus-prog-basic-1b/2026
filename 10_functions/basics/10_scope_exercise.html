スコープと引数の渡し方（初級）¶

関数や変数のスコープを理解し、値渡しと配列渡しの違いを確認します。 各課題では、プログラムを修正・完成させて動作を確かめましょう。

1. スコープの範囲を確認しよう¶

ファイル名：exe10_s_1.c

要件： for文の中で変数を宣言しているため、外側で参照できずエラーになります。 変数を正しく扱い、繰り返し後に回数を表示するプログラムを書け。

#include <stdio.h>

int main(void){
    for(int i=0; i<5; i++){
        printf("%d回目の処理\n", i);
    }
    printf("合計%d回繰り返しました。\n", i); // ← エラーになる
    return 0;
}

2. ブロック内の変数が外に影響しない¶

ファイル名：exe10_s_2.c

要件： 税率を一時的に変更して計算しているが、外に影響しないようにしたい。 ブロックを使ってスコープを分けるプログラムを書け。

#include <stdio.h>

int main(void){
    double tax = 1.1;
    printf("通常税率: %.1f倍\n", tax);

    // このprintfだけ一時的に税率を1.08にしたい
    printf("期間限定セール税率: %.2f倍\n", tax);

    printf("戻った後の税率: %.1f倍\n", tax);
    return 0;
}

3. 関数で変数を変更しても反映されない¶

ファイル名：exe10_s_3.c

要件： 在庫数を1減らす関数を作成したが、main関数の在庫が変化しない。 関数の戻り値を使って、正しく在庫を更新するプログラムを書け。

#include <stdio.h>

void sellItem(int stock){
    stock = stock - 1;
}

int main(void){
    int stock = 10;
    sellItem(stock);
    printf("残り在庫: %d個\n", stock);
    return 0;
}

5. 値渡しと配列渡しの違いを確認する¶

ファイル名：exe10_s_5.c

要件： 点数（変数）と配列を別々の関数でリセットするプログラムを書け。 実行結果から、どちらが実際に変更されたか確認せよ。

#include <stdio.h>

void resetScore(int score){
    score = 0;
}

void resetAll(int data[3]){
    for(int i=0; i<3; i++){
        data[i] = 0;
    }
}

int main(void){
    int score = 100;
    int points[3] = {10, 20, 30};

    resetScore(score);
    resetAll(points);

    printf("score=%d\n", score);
    for(int i=0; i<3; i++){
        printf("points[%d]=%d\n", i, points[i]);
    }
    return 0;
}
